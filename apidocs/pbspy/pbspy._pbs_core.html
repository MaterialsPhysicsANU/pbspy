pbspy._pbs_core¶

Core PBS operations: qsub submission, qstat polling, and result file reading.

These functions are used by pbspy.LocalBackend and are also available to applications that need lower-level PBS state queries.

pbspy._pbs_core.pbs_wait_for_jobs(jobs: list[pbspy.Job], on_update: collections.abc.Callable[[str, str | None], None] | None = None) → None¶

Poll qstat until all jobs in jobs have finished.

Parameters:

  • jobs – The jobs to wait for.

  • on_update – Optional callback invoked on each status change. Called as on_update(job_id, state) where state is one of "Q", "R", "E", "F" or None when the job has disappeared from qstat (finished).
